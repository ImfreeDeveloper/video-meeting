# Issue генератор

Прочитай план из файла: $ARGUMENTS

Для каждой фазы создай milestone и issues в GitHub, используя gh CLI.   

## Порядок действий

1. Прочитать файл плана (путь передаётся через arguments).
2. Для каждой фазы создать milestone с помощью GitHub CLI:
`gh api repos/{owner}/{repo}/milestones --field title="Фаза N: название"`
3. Для каждой задачи в фазе создай Issue:
`gh issue create --title "..." --body "..." --label "..." --milestone "..."`

## Формат Issue
**Title:** текст задачи из плана (без[])
**Body:** описание задачи

## Правила разбивки на фазы:

- Каждая фаза должна давать рабочий результат.
- Фазы независимы, можно остановиться после любой.
- Первая фаза как минимальный рабочий путь (Tracer Bullet)
- Не больше пяти задач в одной фазе
- Backend и frontend одной фичи разной фазы.
- В каждой фазе должны быть запланированные тесты для покрытия функционала фазы

## Правила:

- Читай PRD внимательно, план должен покрывать все критерии готовности.
- Не добавляй задачи, которых нет в PRD.
- Если PRD не полный, задай вопрос перед созданием плана.
