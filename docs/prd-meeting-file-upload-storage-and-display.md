# PRD: Meeting File Upload, Storage, and Display

**Дата**: 2026-09-17
**Статус**: Draft

## Цель

Дать пользователю возможность прикрепить к встрече один или несколько файлов (запись встречи или сопутствующий документ), сохранить их на сервере и видеть список прикреплённых файлов на странице встречи, чтобы материалы встречи не терялись и были доступны для последующей обработки.

## Пользовательский сценарии

- Пользователь открывает страницу встречи, нажимает "Загрузить файл", выбирает файл на устройстве -> файл загружается на сервер и появляется в списке файлов встречи.
- Пользователь открывает страницу встречи, у которой уже есть прикреплённые файлы -> видит список файлов с именем, типом и размером каждого.
- Пользователь нажимает на файл в списке -> файл скачивается / открывается для просмотра.
- Пользователь пытается загрузить файл недопустимого формата или превышающий лимит размера -> видит понятную ошибку, файл не сохраняется.
- Пользователь пытается открыть файл, прикреплённый к чужой встрече -> получает отказ в доступе.
- Пользователь удаляет прикреплённый файл со встречи -> файл исчезает из списка и больше не доступен по прежней ссылке.

## В скоупе

- Загрузка файла на встречу через API (`POST`, привязка к существующей встрече по `meetingId`).
- Поддерживаемые типы файлов: аудио (mp3, wav, m4a), видео (mp4, mov), документы (pdf, docx, txt).
- Несколько файлов на одну встречу (список вложений, не единичное поле).
- Хранение загруженных файлов на локальной файловой системе (диске) сервера api; в базе данных — метаданные файла (id, meetingId, имя файла, MIME-тип, размер, путь хранения, дата загрузки, кто загрузил).
- Ограничение на максимальный размер одного файла и список допустимых MIME-типов, с отклонением загрузки при нарушении.
- Эндпоинт получения списка файлов встречи.
- Эндпоинт скачивания/получения конкретного файла по id, доступный только владельцу встречи.
- Эндпоинт удаления файла со встречи (только владелец встречи).
- Интерфейс на странице встречи (web): блок загрузки файла (выбор файла + индикатор прогресса/статуса загрузки) и список уже прикреплённых файлов (имя, тип, размер, дата, действия "скачать"/"удалить").
- Отображение состояния ошибки загрузки (неверный формат, превышен размер, ошибка сети) в интерфейсе.

## Не в скоупе

- Любая обработка содержимого файла: транскрипция, распознавание речи, извлечение саммари, NLP-анализ и т.п. Файл только сохраняется и становится доступен — обработка будет отдельной фичей поверх этого хранилища.
- Просмотр аудио/видео прямо в браузере (плеер) — только скачивание/открытие файла.
- Редактирование или замена уже загруженного файла (только загрузка нового и удаление старого).
- Совместное использование файла между несколькими встречами.
- Внешние объектные хранилища (S3 и аналоги) — в этой итерации используется локальный диск сервера.
- Версионирование файлов.
- Антивирусная проверка загружаемых файлов.
- Массовая (bulk) загрузка нескольких файлов за один запрос.

## Технические ограничения

- Файл может быть прикреплён только к существующей встрече, доступной пользователю (владелец встречи).
- Хранение на локальном диске сервера api привязывает файлы к конкретному инстансу сервера — без сетевой файловой системы горизонтальное масштабирование api с этой фичей не работает.
- Должен быть задан максимальный размер одного файла и белый список MIME-типов на уровне API; загрузка вне этих ограничений отклоняется до записи на диск.
- Доступ к скачиванию/удалению файла проверяется через `JwtAuthGuard` и сверку `ownerId` встречи с текущим пользователем, аналогично существующим эндпоинтам `meeting`.

## Критерии готовности

- [ ] Пользователь может загрузить файл (аудио/видео/документ из поддерживаемого списка) на существующую встречу через интерфейс.
- [ ] Загруженный файл сохраняется на диске сервера, метаданные — в базе данных, связанные с `meetingId`.
- [ ] Страница встречи показывает список всех прикреплённых к ней файлов с именем, типом и размером.
- [ ] Пользователь может скачать/открыть ранее загруженный файл со страницы встречи.
- [ ] Пользователь может удалить прикреплённый файл, после чего он пропадает из списка и недоступен по прежней ссылке.
- [ ] Загрузка файла недопустимого формата отклоняется с понятной ошибкой в интерфейсе, файл не сохраняется.
- [ ] Загрузка файла, превышающего максимальный размер, отклоняется с понятной ошибкой, файл не сохраняется.
- [ ] Пользователь не может получить доступ (просмотр/скачивание/удаление) к файлам чужой встречи.
- [ ] Встреча поддерживает несколько прикреплённых файлов одновременно.
